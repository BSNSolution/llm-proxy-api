# Security Policy

## Important context

LLM Proxy API exposes access to the LLM subscriptions/CLIs installed on the host.
An API key generated by this app is effectively a credential to use those
subscriptions. Operators are responsible for keeping the proxy off the public
internet (localhost, private network, VPN such as Tailscale, or HTTPS + auth).

Hardening already in place:

- Session cookies are `httpOnly`, stored server-side; the session secret is
  auto-generated and persisted (no insecure default).
- Proxy API keys are hashed with argon2id (only a prefix is stored in clear for lookup).
- Per-user isolation (owner checks) on keys and chats; RBAC (admin/viewer).
- Command spawning uses an env allowlist and never `shell: true` with user input.
- Default network bind is `127.0.0.1`.

## Reporting a vulnerability

Please **do not** open a public issue for security problems.

Instead, report privately via GitHub's
[Security Advisories](https://github.com/BSNSolution/llm-proxy-api/security/advisories/new)
(preferred), or contact the maintainers directly.

Include: a description, steps to reproduce, affected version/commit, and impact.
We'll acknowledge receipt and work with you on a fix and coordinated disclosure.

## Supported versions

This project is under active development; security fixes target the latest `main`.
